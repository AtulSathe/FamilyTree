Test Helpers

FamilyTreeTestFactory.cs — custom WebApplicationFactory

Replaces SQL Server with EF Core InMemory (unique DB per factory instance), GraphDbContext with FakeGraphDbContext, enforces mock auth, and seeds the InMemory DB manually. Provides three role-specific client factories.

public class FamilyTreeTestFactory : WebApplicationFactory<Program>
{
    private readonly string _dbName = Guid.NewGuid().ToString();

    public FamilyTreeTestFactory()
    {
        // Set env var before Program.cs reads configuration during service registration.
        // Without this, .NET 8 auto-adds UseAuthentication() because
        // AddAuthentication services are present from AddMicrosoftIdentityWebApiAuthentication.
        Environment.SetEnvironmentVariable("USE_MOCK_AUTH", "true");
    }

    protected override void ConfigureWebHost(IWebHostBuilder builder)
    {
        builder.UseEnvironment("Testing");

        builder.ConfigureAppConfiguration((_, cfg) =>
            cfg.AddInMemoryCollection(new Dictionary<string, string?>
            {
                ["USE_MOCK_AUTH"]              = "true",
                ["CosmosDb:GremlinEndpoint"]   = "localhost-fake",
                ["CosmosDb:EnableSsl"]         = "false",
                ["AzureBlob:ConnectionString"] = "UseDevelopmentStorage=true",
                ["AzureBlob:ContainerName"]   = "person-photos"
            }));

        builder.ConfigureServices(services =>
        {
            // Replace SQL Server with InMemory
            var sqlDesc = services.Single(d => d.ServiceType == typeof(DbContextOptions<AppDbContext>));
            services.Remove(sqlDesc);
            services.AddDbContext<AppDbContext>(opts => opts.UseInMemoryDatabase(_dbName));

            // Replace Gremlin with no-op stub
            var graphDesc = services.Single(d => d.ServiceType == typeof(GraphDbContext));
            services.Remove(graphDesc);
            services.AddSingleton<GraphDbContext, FakeGraphDbContext>();
        });
    }

    protected override IHost CreateHost(IHostBuilder builder)
    {
        var host = base.CreateHost(builder);
        using var scope = host.Services.CreateScope();
        var db = scope.ServiceProvider.GetRequiredService<AppDbContext>();
        db.Database.EnsureCreated();
        DataSeeder.SeedAsync(db).GetAwaiter().GetResult();
        return host;
    }

    public HttpClient AsPowerAdmin()    => CreateClientAs("power_admin");
    public HttpClient AsSatheAdmin()    => CreateClientAs("family_admin");
    public HttpClient AsCommunityMember() => CreateClientAs("community_member");
}
FakeGraphDbContext.cs — no-op Gremlin stub

Uses the protected no-arg constructor of GraphDbContext to skip the real GremlinClient. All query methods return empty collections.

public class FakeGraphDbContext : GraphDbContext
{
    public FakeGraphDbContext(IConfiguration _) : base() { }

    public override Task<IReadOnlyCollection<IDictionary<string, object>>> QueryAsync(
        string gremlin, Dictionary<string, object>? bindings = null) =>
        Task.FromResult<IReadOnlyCollection<IDictionary<string, object>>>(
            Array.Empty<IDictionary<string, object>>());

    public override Task<T?> ScalarAsync<T>(
        string gremlin, Dictionary<string, object>? bindings = null)
        where T : default =>
        Task.FromResult<T?>(default);
}

Bugs Fixed

Bug #1 — Missing using Xunit; in 5 test files + helpers
Root cause: Microsoft.NET.Sdk implicit usings don't include Xunit namespace. xUnit 2.x doesn't add implicit global usings (only xUnit 3.x does).
Fix: Added using Xunit; to all 5 test files and using Microsoft.AspNetCore.Hosting;, using Microsoft.Extensions.Hosting;, using Microsoft.Extensions.DependencyInjection;, using Microsoft.Extensions.Configuration; to helper files.
Bug #2 — HealthCheckTests using wrong factory (SQL Server connection error)
Root cause: HealthCheckTests used plain WebApplicationFactory<Program> which runs the "Development" environment and calls MigrateAsync() against SQL Server with no connection string.
Fix: Changed to use FamilyTreeTestFactory (InMemory DB, "Testing" environment, skips migration).
Bug #3 — Azure AD B2C auth running in tests (IDW10106: ClientId option must be provided)
Root cause: .NET 8 Minimal API auto-injects UseAuthentication() and UseAuthorization() when AddAuthentication services are registered. FamilyTreeTestFactory.ConfigureAppConfiguration runs after Program.cs already read USE_MOCK_AUTH from config, so AddMicrosoftIdentityWebApiAuthentication was called, registering auth services, which triggered the auto-inject.
Fix: Added Environment.SetEnvironmentVariable("USE_MOCK_AUTH", "true") to FamilyTreeTestFactory's constructor. This sets the env var before any factory host creation; Program.cs reads it via Environment.GetEnvironmentVariable("USE_MOCK_AUTH") and skips Azure AD B2C.
Bug #4 — FakeGraphDbContext tried to connect to Gremlin server
Root cause: FakeGraphDbContext(IConfiguration config) : GraphDbContext(config) called the real base constructor which creates a GremlinClient and attempts a WebSocket connection to localhost-fake:443 immediately on construction.
Fix: Added protected GraphDbContext() { } no-op constructor to GraphDbContext. Changed _client to nullable. Changed FakeGraphDbContext to call : base() skipping the real client creation entirely. Updated Dispose() to null-safe _client?.Dispose().

Key Decisions & Assumptions

DecisionReasoning
Environment variable over configuration for USE_MOCK_AUTH Configuration additions via ConfigureAppConfiguration have uncertain timing relative to Program.cs service registration in .NET 8 Minimal API. Environment variables are always read first by WebApplicationBuilder. Setting the env var in the factory constructor guarantees it's visible before any host code runs.
All test classes use FamilyTreeTestFactory Even HealthCheckTests now uses FamilyTreeTestFactory — the factory provides InMemory DB + "Testing" environment, which skips MigrateAsync and SQL Server connections. There's no reason to use the plain factory.
Protected no-arg constructor on GraphDbContext Alternative (making GraphDbContext implement an interface) would require changing all service registrations. The protected constructor is a minimal, non-breaking change that enables test subclassing.
Unique InMemory DB name per factory instance (Guid.NewGuid().ToString()) Each IClassFixture<FamilyTreeTestFactory> creates its own factory. Unique DB names prevent cross-test-class contamination (e.g., persons created in AuditLogTests don't appear in PersonEndpointTests).
DataSeeder called in CreateHost, not ConfigureServices ConfigureServices runs before the host is built; the AppDbContext isn't yet resolvable. CreateHost override runs after the host is fully built, where scoped services can be resolved normally.
AuditLog tests check row count before/after mutation The InMemory DB is shared within a test class fixture. Checking the count delta (after > before) rather than an absolute count handles rows already seeded or created by earlier tests in the same class.
